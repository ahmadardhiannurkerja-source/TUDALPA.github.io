Rancangan teknis untuk mengembangkan prototipe menjadi sistem TU yang digunakan bersama.

Mode prototipe

Versi ini berjalan di browser dan menyimpan data pada penyimpanan lokal perangkat. Belum ada login sungguhan, server, database bersama, atau backup otomatis. Gunakan data simulasi saja sampai backend dipasang.

Cara menjalankan
Untuk prototipe ini dan pengembangan berikutnya
1. Coba prototipe
Gunakan menu Data Santri, Catat Pembayaran, Tunggakan, dan Laporan.
Browser
2. Uji dengan data contoh
Tambah santri, catat pembayaran, cetak kuitansi, lalu ekspor CSV.
Simulasi
3. Bangun backend
Buat API menggunakan Node.js/Express, Laravel, atau framework sejenis; sambungkan ke PostgreSQL/MySQL.
Pengembangan
4. Deploy dengan aman
Pasang di hosting/server dengan HTTPS, akun petugas, backup, dan pengujian pemulihan.
Produksi

Penting: data pada prototipe tersimpan hanya di browser yang sama dan bisa hilang jika data situs dihapus. Ekspor CSV bukan pengganti backup database. Jangan gunakan untuk pencatatan resmi sebelum backend dan kontrol keamanan tersedia.
